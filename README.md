# FitMate — AI-Powered Fitness App

FitMate is an Android fitness app that helps users track their diet, workouts, and health metrics with the help of AI.

## Tech Stack

- React Native (Expo)
- Firebase Authentication & Firestore
- OpenAI API

---

## Features

- User authentication (login, signup, password reset)
- AI-generated weekly diet plans
- Personalized workout routines
- Health metrics — BMI, BMR, TDEE, Body Fat
- AI fitness coach chatbot
- Subscription tiers (Free, Pro, Ultra)
- Admin panel for user management

---

## How to Run

```bash
npm install
npx expo start
```

Scan the QR code with the **Expo Go** app on your phone.
